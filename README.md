# TP-01-Logiciels-Libres



## Introduction
Ce travail pratique porte sur la découverte et l'utilisation des logiciels libres et open source.

## Objectif
Apprendre à utiliser GitHub, créer un dépôt et organiser les fichiers d'un projet.

## Outils utilisés
- GitHub
- Navigateur Internet
- Ordinateur ou smartphone

## Conclusion
Ce TP nous permet de découvrir GitHub et de comprendre comment créer et organiser un dépôt pour un projet.
